# Заявки Trading Party → Google Sheets

Форма регистрации на лендинге отправляет заявки в Google-таблицу через Apps Script.
Никакого сервера — только таблица + скрипт.

## Как подключить (10 минут, нужен твой Google-аккаунт)

1. **Создай таблицу**: [sheets.new](https://sheets.new). Назови, например, «Trading Party — заявки».
2. **Открой редактор скрипта**: в таблице → **Расширения → Apps Script**.
3. **Вставь код**: удали содержимое `Code.gs` в редакторе, вставь код из [`Code.gs`](Code.gs) рядом, **сохрани** (⌘S).
4. **Задеплой как веб-приложение**:
   - **Deploy → New deployment**
   - шестерёнка → тип **Web app**
   - **Execute as:** `Me` (ты)
   - **Who has access:** `Anyone`
   - **Deploy** → подтверди доступ к своему Google-аккаунту (Authorize).
5. Скопируй **Web app URL** (заканчивается на `/exec`).
6. Пришли его мне — я впишу в сайт (`TP_CONFIG.sheetEndpoint`) и раскатаю. Либо впиши сам в
   `site/index.html`:
   ```js
   window.TP_CONFIG = {
     registrationEnds: "",
     sheetEndpoint: "https://script.google.com/macros/s/…/exec",
     registrationUrl: ""
   };
   ```

Лист **«Заявки»** создастся сам при первой отправке. Столбцы: дата, имя, email, телефон, Telegram, язык, источник, user-agent.

## Проверка

Открой Web app URL в браузере (GET) — должно вернуть `{"ok":true,...}`. Отправь тестовую заявку с сайта — строка появится в таблице.

## Как это работает / безопасность

- Форма шлёт `POST` (form-urlencoded, `no-cors`) — простой запрос без CORS-преград; строка пишется всегда, ответ не читаем, успех показываем по факту доставки.
- **Honeypot**: скрытое поле `website`. Если бот его заполнил — заявка тихо игнорируется.
- Клиентская валидация: имя, телефон, email и согласие обязательны.
- **Важно:** URL веб-приложения публичный (форма шлёт на него). Спам-защита — только honeypot + валидация. Если пойдёт спам, добавим reCAPTCHA или секретный токен в запросе (проверять в `doPost`).

## Заметки

- Обновил код скрипта → нужно **Deploy → Manage deployments → Edit → New version**, иначе изменения не применятся.
- Уведомления о новых заявках можно навесить триггером (`onFormSubmit`-подобный) или отдельной функцией с `MailApp`/Telegram-ботом — скажи, добавлю.
- Когда FYNXT выдаст свою форму — можно переключиться: заполнить `TP_CONFIG.registrationUrl`, наша форма заменится на их iframe (заявки в Sheets останутся как запасной канал).
